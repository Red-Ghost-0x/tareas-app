# Mi Lista de Tareas

Aplicación de tareas hecha con React, TypeScript, Vite y Tailwind CSS.

## Requisitos

- Instalar la version mas reciente de NodeJS desde su pagina oficial: https://nodejs.org/en 
- npm  

## Cómo ejecutarlo desde la terminal de Visual Studio Code

- npm install  <!--Para descargar modulos y dependencias necesarias para correr proyecto-->
- npm run dev  <!--Correr proyecto-->

Abre la dirección que muestra la terminal (por ejemplo http://localhost:5173).


## Estructura

```
src/
  components/   componentes de la interfaz
  interfaces/   tipos e interfaces
  hooks/        hooks personalizados
  services/     acceso a almacenamiento y a la API
  styles/       estilos deTailwind
  server/       API de archivo para el servidor de Vite
  db/           todos.ts con las tareas guardadas
```
